Sift

Sift is a self-contained agent skill for searching local text files and exporting matches to CSV. Ask for a search in conversation; the skill runs its bundled Python helper and reports matching file locations, skipped files, and incomplete results.

I started with a Go command-line tool. As it accumulated features like color coding and editor integration, I stepped back and rebuilt it as a smaller skill with a Python script. The original branch shows what I cut and what the simpler version kept.

AI Agent Skills

A personal collection of agent skills written to support the software development lifecycle and shared publicly for others to use. Personal and business-specific information has been extracted so the skills can be reused independently.

  • dev-server-setup sets up a local Docker development environment for an application.
  • bug-diagnoser investigates software bugs and verifies likely causes before implementation.

Bargain

Bargain is an Elixir library for converting Markdown to HTML.

I started with a test for a single heading and expanded the parser one feature at a time. The article series follows those decisions from headings to links and blockquotes.
